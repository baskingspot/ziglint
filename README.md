Opinionated linting to keep your agent in check.

A compiler does not care that a function is named `MyBadName`, that an import is unused, or that a materialized type hides a private one. An agent learns the same way, from the error it gets, and there is no error to get. ziglint reads the AST that `std.zig.Ast` gives it and reports the 34 things the house style says are wrong, each with a note that says why.

It has no dependencies, runs on the Zig tree you point it at, and prints one line per finding: `Z024: src/Linter.zig:31: line exceeds 120 bytes (252 bytes)`.

## What is in it

- [Rules](https://baskingspot.dev/ziglint/#rules): what the 34 checks cover, and how `--only` and `--ignore` pick one. The [rule reference](https://baskingspot.dev/ziglint/rules/) has the note for each.
- [Inline ignores](https://baskingspot.dev/ziglint/#inline-ignores): `// ziglint-ignore: Z001` silences one rule on one line, so a deliberate exception costs one line of prose.
- [Reading a rule](https://baskingspot.dev/ziglint/#reading-a-rule): `ziglint --explain Z024` prints the note in the terminal, and `--list-rules` prints every code and title.

Not implemented:

- An autofix. A finding names the line and the rule, and the edit is yours.
- Formatting. `zig fmt` owns layout, and ziglint never runs it.
- A rule over what a parse cannot see: a name built at comptime, a type that exists only after instantiation, or a generated file.

## Install

ziglint runs `zig` to find the standard library it lints against, so `zig` must be on `PATH`. `--zig-lib-path` points it at another lib directory.

With Homebrew, on macOS or Linux:

```sh
brew install --cask baskingspot/tap/ziglint
```

With mise:

```sh
mise use -g github:baskingspot/ziglint
```

With Nix:

```sh
nix run github:baskingspot/ziglint -- src
```

Each [release](https://github.com/baskingspot/ziglint/releases) has a tarball for `linux-x64`, `linux-arm64`, and `macos-arm64`, a zip for `windows-x64`, and a `SHA256SUMS` file. The archives are attested, so check a download with `gh attestation verify FILE -R baskingspot/ziglint --signer-repo baskingspot/gh-actions`.

From source:

```sh
zig build install -Doptimize=ReleaseFast --prefix $HOME/.local
```

## Work on it

```sh
nix develop
just ci
```

`nix develop` provides the toolchain and the site tools. `just` lists the recipes, `just ci` runs what CI runs, `just guide` serves the guide with live reload, and `just doc` builds the whole site into `zig-out/site/ziglint/`. The rule and changelog pages are generated by `zig build site`.
